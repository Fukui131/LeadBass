# LeadBass

ベース初心者向けの操作可能なNext.jsプロトタイプです。

## 起動

Node.js 22.18以降（テストにNode標準のTypeScript実行を利用）。

```sh
npm install
npm run dev
```

http://127.0.0.1:3000 を開きます。

## 確認とビルド

```sh
npm run typecheck
npm test
npm run build
```

Next.js App Router / TypeScript / React 19 / Lucide。`output: 'export'` のため、ビルド後の `out/` を静的ホスティングへ配置できます。サーバーAPI・データベースは不要です。フォントはGoogle Fontsから取得し、オフライン時はシステムフォントへフォールバックします。

## 実装内容

- `/` — 達成率、練習時間、学習日、週間カレンダー、学習履歴、次のレッスン。
- `/lessons/` / `/lessons/1/`〜`/lessons/7/` — 7レッスン各2ステップ。進行位置の保存、完了記録、復習。
- `/quiz/` — 5問。4択と指板選択、正誤解説、最高正答率、間違えた問題だけの復習。
- `/practice/` — 4フレーズ、30〜220 BPM、4拍カウント、TAB譜と指板の同期、停止・再開・ループ。4分・8分・2分音符を扱います。
- `/metronome/` — Web Audioクリック音、拍の表示、3/4・4/4、テンポ入力・スライダー・プリセット・タップテンポ。
- `/results/` — 完了したフレーズ・BPM・時間・周回数、同じフレーズの再練習、明示的なデモ採点。

## プロトタイプの範囲

- **実際の演奏音は取得・採点しません。** 録音やマイク権限の要求はありません。85点・78点は固定の採点サンプルとして明示しています。
- 指板タップでベース音は鳴りません。指板の操作はクイズの位置選択のみです。
- 学習記録はブラウザの `localStorage`（`leadbass-progress-v1`）に保存します。アカウント・端末間同期はありません。
- 練習時間はカウントインと一時停止時間を除き、完奏したセッションを記録します。途中で離れた未完了セッションは記録しません。
- テンポ変更は演奏練習をリセットします。メトロノームはテンポ・拍子変更時に停止します。
- タブが非表示になると一時停止し、画面を移動すると音声・タイマーを片付けます。

## 構成

- `lib/content.ts` — レッスン、クイズ、フレーズの教材データ。
- `lib/music.ts` — 拍数から音符位置を求める時間計算。
- `components/use-transport.ts` — 表示時計、25ms間隔・100ms先読みのクリック音スケジューラー。
- `components/progress-provider.tsx` — ブラウザ保存と学習記録。
- `components/fretboard.tsx` — TAB譜と4弦の指板。

## 検証

型チェック、本番静的ビルド、カウントイン・BPM・音符長・ループ境界の単体テストを実行。ブラウザでレッスン完了、クイズ回答と誤答復習、練習の停止・再開・結果表示、メトロノーム操作、リロード後の記録保持を確認。1440pxと390pxのレスポンシブ表示を確認しています。
